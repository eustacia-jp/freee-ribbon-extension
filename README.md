# Color Ribbon for freee

freeeの画面右上に、ログイン中の事業所名と事業所番号を示す色付きリボンを表示するChrome拡張機能です。

複数の事業所を切り替えながらfreeeを使う際に「どの事業所にログインしているか」を一目でわかるようにすることを目的としています。

**本拡張機能はフリー株式会社が提供する公式の機能ではなく、ユースタシア合同会社の Daiki Mori (yu) によって開発・提供されています。**

## 主な機能

- freeeの画面右上に、事業所名・事業所番号を示すリボンを表示
- 事業所ごとにリボンの色を指定可能
- 本番環境とステージング環境で異なる色を指定可能 (開発者向け)
- リボンを一時的に消す方法を選択可能 (クリックで位置を切り替える/マウスをのせると自動的に消える)
- リボンの不透明度を調整可能
- 事業所番号をダミー文字列で上書き表示可能 (スクリーンショットや動画を撮る際など、実際の番号を隠したい場合)
- リボンを表示しないプロダクト・画面をURLの正規表現で指定可能 (初期状態でfreee請求書・freee申告は非表示)
- 対応プロダクト: freee会計、freee人事労務、freee会社設立、freeeマイナンバー管理、freee請求書、freee申告 ほか

## インストール

### Chromeウェブストアから (推奨)

[Color Ribbon for freee - Chrome ウェブストア](https://chromewebstore.google.com/detail/color-ribbon-for-freee/bpfkbiddimcmmkgjeijbmpginlepjebj)

### 開発者モードで手動インストール

1. このリポジトリをダウンロード (またはクローン) する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選択する

## 設定

拡張機能アイコンから「オプション」を開くと、以下の設定ができます。

- リボンの表示/非表示、不透明度、一時的な消し方
- 事業所ごとの色設定
- 開発者向け設定 (ステージング環境の判定・各種デフォルト色・事業所番号の上書き・リボンを表示しないURL)
